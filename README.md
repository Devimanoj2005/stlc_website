# STLC 2026 | IEEE ComSoc Student Tech Leadership Conference

> **Where Technology Meets Leadership**  
> Official web platform for the IEEE ComSoc Student Tech Leadership Conference (STLC) 2026.

---

## Overview

**STLC 2026** is a premier two-day residential conference bringing together students and young professionals passionate about technology, innovation, and leadership.

- **Organized by:** IEEE ComSoc Student Branch Chapter, SJCET (St. Joseph's College of Engineering and Technology, Palai)
- **In Association with:** IEEE ComSoc Kerala Chapter
- **Focus:** Emerging communication technologies, executive leadership skills, career guidance, and applied engineering innovation.

---

## Key Highlights

- **Technical Sessions & Workshops:** Hands-on learning exploring next-gen communications, computing, and engineering.
- **Young Professionals Panel:** Real-world transitions, industry trends, and career roadmaps from early-career leaders.
- **Project Expo:** Competitive exhibition spotlighting hardware, IoT, and software student prototypes.
- **Leadership & Networking:** Collaborative challenges connecting delegates with IEEE professionals and mentors across Kerala.

---

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Library:** React 19
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Typography:** Syne & Plus Jakarta Sans via `next/font`

## Getting Started

### Prerequisites

- [Bun](https://bun.sh/) (recommended) or [Node.js](https://nodejs.org/) (v18+)

### Installation & Development

```bash
# Clone the repository
git clone https://github.com/TimsTittus/stlc_website.git
cd stlc_website

# Install dependencies
bun install

# Start development server
bun dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

### Production Build

```bash
bun run build
bun run start
```
